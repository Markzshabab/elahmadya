# Al Ahmadiya Youth Center Survey PWA

A high-performance Progressive Web Application designed for the residents of Al Ahmadiya Village. 

## Features
- Complete Single Page App built strictly with Vanilla JS/HTML/CSS.
- Native Video/Audio recording (Max 30s) built directly into the browser.
- Real-time Chart.js integrations.
- GSAP and Lottie animations for a premium UI feel.
- Complete backend logic decoupled via Cloudflare Workers.

## Deployment Steps

### 1. Cloudflare R2 & Worker Setup
1. Log into Cloudflare dashboard. Go to R2 and create a bucket named `ahmadiya-media`.
2. Go to Workers & Pages. Create a new worker `survey-api`.
3. Paste the contents of `worker.js` into the worker editor.
4. Bind your R2 bucket in the Worker settings (Variable name: `MEDIA_BUCKET`).
5. Add environment variables `FIREBASE_URL` (your Firebase RTDB URL) and `FIREBASE_AUTH` (Database secret).

### 2. Firebase Setup
1. Create a Firebase project and provision a Realtime Database.
2. Structure: 
   - `/survey/submissions/`
   - `/survey/statistics/`
3. Set Database Rules to secure access (allow read for stats, deny writes directly from client - forcing traffic through Cloudflare Worker).

### 3. GitHub Pages
1. Push this repository to GitHub.
2. Navigate to Repository Settings > Pages.
3. Deploy from `main` branch. 
4. The PWA is now live, fully secure, and globally distributed.
